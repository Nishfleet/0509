## What changed

- `rateLimitPolicyFor`: GET/HEAD under `/auth/*` and `/api/auth/*` → new scope `auth-anon-get`, 60/60s per-IP, binding `RL_AUTH_GET`, `humane429`. Sized to clear the 24-GET/10-min burst plus a two-device walk (~10 auth-scope GETs) inside one 60s window with room to spare. Every non-GET/HEAD auth call keeps `auth` 2/60s, fail-closed, exactly as #2964's legacy mapping.
- `humane429` (the money-path scope only): a 429 now returns readable HTML — "Checking faster than we allow / Try again in a few minutes", Retry-After echoed in the copy — never a bare status or the raw JSON envelope. Retry-After: 60 preserved in the header either way. Every other scope keeps the JSON envelope.
- `RL_AUTH_GET` binding added to `wrangler.jsonc`, `wrangler.e2e.jsonc`, `tests/integration/wrangler.test.jsonc` (60/60s, namespace 1012 — mirrors the 1001…1011 ratelimit numbering, verified on today's main), the fixtures, and `EdgeRateLimitBindingName`.
- New `scripts/verify-money-path-200s.sh` (acceptance 5, the house live-probe pattern): fresh session, the 4-step walk ×2 devices, then the 24-GET /auth/signup burst at ≤1 rps; exit 0 only when every request is 200, printing each code; 429s get their Retry-After printed.

Not changed: the public-brand-page budget (#3156's #3360 set it; this diff touches it nowhere), the proof-brief bucket, every other scope, `migrations/**`, `.github/**`. No test removed — every test-side hunk is additive.
