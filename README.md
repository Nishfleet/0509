# 0509

0509 is a frontend-first competitor ad research product for growth teams.

## Routes

- `/` homepage
- `/search` open Meta Ad Library demo
- `/waitlist` fallback page when no external Tally URL is configured

## Environment

Set a real Tally destination when ready:

```bash
NEXT_PUBLIC_WAITLIST_URL=https://tally.so/r/your-form-id
```
