## Risks
- **Vacuous enumeration** — the mandated guard: the derivation must be asserted non-empty (sneakerping present in both slug sets, `compare.sneakerping.tsx` in the filename set, `compareEntries.length > 0`) or a broken `readdirSync`/regex walks nothing and the parity legs pass silently. A `readdirSync` ENOENT throws loudly, which is fine.
- **Non-recursive readdir** — the derivation reads `app/routes` only. If compare routes ever move into a subdirectory, the derivation under-counts and legs (b)+guards fail loudly; the fix is the derivation, not the routes.
- **#1878 it() edit fragility** — title must stay byte-identical; the 2 existing loser expects and the 2 loop-body expects must survive verbatim; no `as const` on the folded computed array. Expect-count lands strictly net-positive (gate-integrity counts assertions); any removal would need the `test-removal-justified` trailer.
- **TS const-assertion trap** — `as const` on the `.map()`-built winners array is a compile error; declare it `: readonly string[]`.
- **Loc casing** — `renderSitemapXml` lowercases `<loc>` paths; all compare slugs are already lowercase, so the `xml.toContain` assertions are case-safe today. If a future compare slug ever gains uppercase, that assertion (not the parity) is what catches it.
- **Test-run discipline** — only `npx vitest run tests/sitemap.server.test.ts`; never coverage/typecheck/`--maxWorkers`; respect `VITEST_MAX_WORKERS`; one heavy toolchain at a time (fleet-ops#4891). The `--reporter=dot` optional one-line form is allowed; note Vitest 4 removed the long `basic` spelling.
- **Scope creep** — the #1878-termination it(), the #2031 honesty it(), the #2081 it(), and `SITEMAP_PATHS` itself are adjacent; edit only what the phases name. Production 404 on `/compare/sneakerping` is the #3166 deploy gap — informational, not this defect.
