Read this whole file before touching anything. It is short on purpose.

## What this is
Five to Nine (0509.io): watches you across the internet and tells you where you stand, you and your competition. Brands and creators. Ads on every platform, mentions everywhere, site changes, hiring. The full product spec is issue #3842 and every comment on it; the contracts are `docs/REBUILD-*.md`. Nothing else is spec.

## The rules that end a PR on sight
1. **No glue, no hand-rolled anything.** No `scripts/`, `ops/`, hooks, wrappers, adapters, helper files, custom schedulers, diffing, crawlers, queues, retries, auth, billing, email, charts or design systems. Every capability uses the library or Cloudflare primitive named in `docs/REBUILD-STACK.md`, as shipped, at the version named there. A PR must name what it uses and what it rejected.
2. **Nothing from the pre-wipe code is reused.** Main was emptied at fa9d48aa4. Old files may be read for facts about an outside API (`git show 668d2452c:<path>` in a read-only worktree), never copied, never checked out beside a build.
3. **Roles.** Fable orchestrates and checks. The Opus deputy does research, design, architecture, packets and every review. Fleet workers execute tight packets only, with no design choice left. Research or design written by a worker is discarded, not corrected.
4. **Proofs are real records** with an id, path or timestamp. Invented samples never count. "Complete" is `docs/REBUILD-DONE.md`, nothing less.
5. **Cost.** Near-zero Cloudflare: writes batched, blobs in R2, counters in KV/DO, Browser Rendering capped at 10 concurrent sessions (a config value; raising it needs Nish's yes with the cost in the PR, and never left to degrade customers). See `docs/REBUILD-COST.md`.
6. **Jev decides every typed decision** (`docs/REBUILD-JEV.md`). Code never guesses with regexes where a judgment is needed.
7. **Guardrails** (`docs/REBUILD-GUARDRAILS.md`): brands and creators only, never private individuals; disposable identities for collection; paid data providers only with Nish's yes.

## Repo shape (once C4 lands)
React Router 8 framework mode on Cloudflare Workers, generated by the stock CLI. `app/` routes and components (shadcn/ui on Tailwind 4), `workers/` entry, `migrations/` (a single `0001_rebuild.sql` reset, then numbered files), `tests/` (vitest with the Workers pool) and `e2e/` (Playwright against production). `package.json` scripts: `build`, `dev`, `test`, `typecheck`, `deploy`. Workflows: `ci.yml`, `deploy-production.yml` only; required checks are `codex-node-checks`, `Gitleaks`, `semgrep`, `preview-assert` by exact name. Push to `main` deploys.

## Working here
- `git fetch origin`, branch from `origin/main`, push within five minutes, commit by pathspec, never `git add -A`, never bare `git stash`. No `.lane/` or report files in the repo; the PR description is the report.
- Migrations: `wrangler d1 migrations list` is the authority on what production has applied; never restate a tip number here.
- Voice and design: `DESIGN.md`. Sentence case in the app, no exclamation marks, empty states say what fills them and when.
- Secrets: GitHub repo secrets only, synced by the deploy workflow. Never in the repo, never in a doc.
