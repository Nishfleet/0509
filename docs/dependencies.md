# Every package.json dependency

The dependency allowlist, and the only file in the repo that holds it.
**Adding a dependency that is not in this table is a rejection**, not a review
comment (AGENTS.md). `tests/stack-dependencies.test.ts` fails the build when any
tracked `package.json` names one without a row here, in every dependency field,
including `devDependencies` (0509#4185).

Moved out of [`docs/REBUILD-STACK.md`](REBUILD-STACK.md) §9 on 2026-10-05
(0509#7017). That file is 190 KB of 2026-09 probe notes, so an agent adding one
dependency had to open all of it to find the table. The **Where it is named**
column still cites a section of `docs/REBUILD-STACK.md`: §1.1 there means §1.1 of
that file.

The version in this table is the `package.json` specifier. A section of `docs/REBUILD-STACK.md` often names the same number without the caret. `^` means the lockfile may resolve a later patch or minor; where it has, the resolved version is in the last column.

deliberately does not catch it, so it is recorded here instead. Two tools are used to
