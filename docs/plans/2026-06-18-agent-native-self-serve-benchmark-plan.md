# 0509 agent-native self-serve benchmark plan

Date: 2026-06-18

## Objective

Assess 0509 against current competitor intelligence, ad monitoring, and website change tools, then identify additions that would make the product meaningfully differentiated, agent-native, and self-serve capable.

## Method

1. Read repo memory and current product docs for stable context.
2. Inspect the active app routes and server modules that define current customer-facing capabilities.
3. Verify live public surfaces at `0509.io` for buyer-facing truth.
4. Run current-signal research on competitor ad monitoring and adjacent tools.
5. Benchmark competitor categories against 0509 on proof, monitoring, self-serve activation, agent/API access, and actionability.
6. Use agent-native architecture criteria to identify the highest-leverage capability gaps.
7. Return a ranked recommendation with launch-blocker, near-term, and moat-building work.

## Evaluation Criteria

- Does the addition strengthen the proof-backed "what changed" wedge?
- Can a self-serve customer reach first value without operator help?
- Can an agent do the same useful work a human can do in the app?
- Does the feature create retained weekly use, not just one-off search?
- Is the claim supportable by live product behavior and public copy?

## Expected Deliverable

A decision-shaped strategy recommendation with:

- Current 0509 strengths and gaps.
- Competitor benchmark by category.
- The one highest-leverage product bet.
- A prioritized roadmap for agent-native and self-serve readiness.
