feat(onboarding): offer adjacent tracked brands and a landing-page capture when the scan finds no ads

Closes #2411

## What

In the `no_ads` first-brief state, a brand-new user's first product impression no longer dead-ends on "No verified ads yet" + a generic "Add competitors" link:

1. **Brands we already track** — up to 3 adjacent already-tracked brands, picked from the same sitemap-indexable set the public `/brands` hub serves (`loadIndexableAdsInternalLinks`), narrowed to the user's competitor's buyer category via the existing `brandCategoryForDomain` registry, with a deterministic alphabetical fallback. Every suggestion links to a live `/ads/:domain` evidence page, so the first session ends somewhere real instead of a wait.
2. **Add a page to capture instead** — routes the user to the competitor they already watch (free plan: `watchlists: 1`) so the next check covers a page they picked. No second watchlist, no invented copy: the offer names only what the plan already includes.
