- `tests/status.route.test.ts` — the #3394 (issue #3197) block added this file's only wall-clock read, `todayDayKey(now: Date = new Date())`. That one default parameter exposed all 56 pre-existing ISO echo fixtures to the guard: a file escapes only with no clock read, a pinned clock, or annotations on every literal. Fix: freeze the clock at test start — `vi.useFakeTimers({ now: new Date(Date.now()) })` in the existing beforeEach, `vi.useRealTimers()` in afterEach — the pinned-clock escape the guard's own failure message grants, and the same shape #3191 itself used (460802e1c, "pinned probe-test clock", where a file carried many fixtures). Test side and loader side then derive the same UTC day key, and the `Checked \d+ min ago` regex keeps its behavior, because the frozen now equals the real now at test start.
- `tests/integration/reddit-mention-connector.integration.test.ts` — one unannotated literal: `expect(first?.publishedAt).toBe("2026-01-01T00:00:00.000Z")`. It is the serialization of `POST_A_CREATED_UTC` (epoch 1_767_225_600), asserted verbatim, never compared against the clock. It now carries `// fixed-date:`, the same precedent line 53 already sets for the epoch constant.

The guard test is untouched: no weakened assertion, no skip, no removal, no `|| true` (motive 1; Nish 2026-09-11).
